GitHub Actions + ntfy 溢价率提醒设置

安全提示：网页需要 GitHub Fine-grained PAT 才能更新仓库里的 config.json。Token 仅保存在当前标签页内存，不会写入网页存储；刷新页面即清除。只授予单个仓库的 Contents 读写权限，保存后建议撤销 Token。不要在公用设备上使用。

使用说明

  1. 仓库需已上传项目文件，且默认分支与上方填写一致。
  2. 在 GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens 创建 Token；Repository access 只选这个仓库，Repository permissions 只开 Contents: Read and write。
  3. 保存会更新仓库根目录的 config.json，阈值按百分数填写，例如 10 表示 10%。
  4. 此页面不会保存 Token。不要把 Token 发给任何人或提交到仓库。
仅供个人提醒；行情接口可能变化，首次启用前必须按 README 验证字段。GitHub Actions 不是精准定时服务。
